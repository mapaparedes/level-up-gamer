# Level-Up Gamer

Proyecto académico de una tienda online de productos para gamers
en Chile, con despachos a todo el país.

## Objetivo

Desarrollar un sitio web básico con HTML, CSS y JavaScript,
aplicando estructura semántica, estilos propios, validaciones
de formularios y trabajo colaborativo mediante GitHub.

## Misión

Proporcionar productos de alta calidad para gamers en todo Chile,
ofreciendo una experiencia de compra única y personalizada,
con un enfoque en la satisfacción del cliente y el crecimiento
de la comunidad gamer.

## Visión

Ser la tienda online líder en productos para gamers en Chile,
reconocida por su innovación, servicio al cliente excepcional
y un programa de fidelización basado en gamificación.

## Tecnologías

- HTML: estructura y contenido.
- CSS: estilos personalizados en archivos externos.
- JavaScript: interacciones y validaciones de formularios.
- Git y GitHub: control de versiones y colaboración.

## Alcance de esta entrega

- Navegación mediante hipervínculos.
- Imágenes, botones y videos.
- Formularios con validaciones y mensajes personalizados.
- Pie de página.
- Diseño visual inspirado en la cultura gamer.

Esta etapa no contempla conexión a una base de datos.
Las funciones que requieran un servidor se representarán
como demostraciones cuando corresponda.
