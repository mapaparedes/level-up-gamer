'Carrito': Guarda productos que el cliente selecciona para su compra.
'Contacto': Tiene informacion sobre la tienda, tales como, número telefonico, correo electrico, direcciòn.
'Img': Contiene la fotografias de los productos y la visualizacion de la pagina web.
'Login': El cliente hace inicio con sus credenciales previamente registradas en el sitio web.
'Nosotros': Esta sesión se encarga de entregarle información al cliente.
'Productos': Aquí se almacena información sobre los productos que se visualizan en la pagina.
'Registro': En esta sesión el cliente hace ingreso de sus datos para poder obtener una cuenta para poder hacer compra de productos
'Index': En este apartado, el cliente puede visualizar la pagina principal.
